\section {Постановка задачи}

Рассматривается нестационарное движение баротропного газа в области $\Omega \subset \mathbb{R}^2$. Неизвестными являются плотность $\rho(t,\mathbf{x})$ и поле скорости $\mathbf{u}(t,\mathbf{x}) = (u_1, u_2)$, зависящие от времени $t$ и координат $\mathbf{x} = (x_1, x_2)$. Уравнения движения записываются в дивергентной форме и включают закон сохранения массы и закон сохранения импульса.

В двумерном случае эта система имеет следующий развёрнутый вид:

\[
\begin{cases}
	\dfrac{\partial \rho}{\partial t} + \dfrac{\partial (\rho u_1)}{\partial x_1} + \dfrac{\partial (\rho u_2)}{\partial x_2} = 0, \\[10pt]
	\dfrac{\partial (\rho u_1)}{\partial t} + \dfrac{\partial (\rho u_1^2)}{\partial x_1} + \dfrac{\partial (\rho u_1 u_2)}{\partial x_2} + \dfrac{\partial p}{\partial x_1}
	= \mu \left( \dfrac{4}{3}\dfrac{\partial^2 u_1}{\partial x_1^2} + \dfrac{\partial^2 u_1}{\partial x_2^2} + \dfrac{1}{3}\dfrac{\partial^2 u_2}{\partial x_1 \partial x_2} \right) + \rho f_1, \\[10pt]
	\dfrac{\partial (\rho u_2)}{\partial t} + \dfrac{\partial (\rho u_1 u_2)}{\partial x_1} + \dfrac{\partial (\rho u_2^2)}{\partial x_2} + \dfrac{\partial p}{\partial x_2}
	= \mu \left( \dfrac{1}{3}\dfrac{\partial^2 u_1}{\partial x_1 \partial x_2} + \dfrac{\partial^2 u_2}{\partial x_1^2} + \dfrac{4}{3}\dfrac{\partial^2 u_2}{\partial x_2^2} \right) + \rho f_2.
\end{cases}
\]

Здесь $\mu \ge 0$ — коэффициент (постоянной) вязкости, $\mathbf{f}(\mathbf{x}) = (f_1, f_2)$ — заданное поле внешних массовых сил. Давление $p$ связано с плотностью уравнением состояния: либо $p = C_\rho \rho$ (с положительной константой $C_\rho$), либо $p = \rho^\gamma$ с показателем $\gamma > 1$.

Система дополняется начальными условиями:
\[
\rho(0,\mathbf{x}) = \rho_0(\mathbf{x}), \qquad \mathbf{u}(0,\mathbf{x}) = \mathbf{u}_0(\mathbf{x}), \quad \mathbf{x} \in \Omega,
\]
и граничными условиями прилипания:
\[
\mathbf{u}(t,\mathbf{x}) = \mathbf{0}, \quad (t,\mathbf{x}) \in [0,T] \times \partial\Omega.
\]

Таким образом, требуется найти функции $\rho(t,\mathbf{x})$, $u_1(t,\mathbf{x})$, $u_2(t,\mathbf{x})$, удовлетворяющие приведённой системе, начальным и граничным условиям.

Для автоматического обеспечения условия положительности функции плотности систему дифференциальных уравнений можно преобразовать к виду
\begin{align*}
	& \cfrac{\partial g}{\partial t} + \frac{1}{2}\sum_{k=1}^{2}\Big(u_k\cfrac{\partial g}{\partial x_k}+
	\cfrac{\partial u_k g}{\partial x_k} + (2-g)\cfrac{\partial u_k}{\partial x_k}\Big) = f_0,\\
	& \cfrac{\partial u_k}{\partial t} + \frac{1}{3}(u_k\cfrac{\partial u_k}{\partial x_k} + 
	\cfrac{\partial u_k^2}{\partial x_k})
	+ \frac{1}{2}\sum_{m=1,m\neq k}^{2}\Big( u_m\cfrac{\partial u_k}{\partial x_m}+
	\cfrac{\partial u_m u_k}{\partial x_m} - u_k\cfrac{\partial u_m}{\partial x_m}\Big)
	+ p’_{\rho } \cfrac{\partial g}{\partial x_k} = \\
	& = \cfrac{\mu}{\rho}\Bigg( \frac{4}{3} \cfrac{\partial^2 u_k}{\partial x_k^2} + 
	\sum_{m=1,m\neq k}^{2}\Big( \cfrac{\partial^2 u_k}{\partial x_m^2} + 
	\frac{1}{3} \cfrac{\partial^2 u_m}{\partial x_k \partial x_m} \Big)\Bigg) + f_k,\ k = 1..s,\\
	& p = p(\rho), \quad g = ln\ \rho.
\end{align*}

\section{Отладочный тест}

Пусть заданы точные гладкие функции \(\rho(t,x_1,x_2)\), \(u_1(t,x_1,x_2)\), \(u_2(t,x_1,x_2)\). Их значения на нулевом временном слое служат начальным приближением. С помощью этих функций вычисляются правые части \(f_0, f_1, f_2\) для неявной разностной схемы. Таким образом получается начально-краевая задача, имеющая известное гладкое решение.

В качестве такого решения выбраны следующие зависимости:

\[
u_1(t,x_1,x_2) = \sin(2\pi x_1)\,\sin(2\pi x_2)\,e^{t},
\]
\[
u_2(t,x_1,x_2) = \sin(2\pi x_1)\,\sin(2\pi x_2)\,e^{-t},
\]
\[
p(t,x_1,x_2) = \left(\cos(2\pi x_1)+\frac{3}{2}\right)\left(\sin(2\pi x_2)+\frac{3}{2}\right)e^{t},
\]
\[
g = \ln p = \ln\!\left(\cos(2\pi x_1)+\frac{3}{2}\right)+\ln\!\left(\sin(2\pi x_2)+\frac{3}{2}\right)+t.
\]

Необходимые производные:

\[
\frac{\partial g}{\partial t}=1,\qquad
\frac{\partial g}{\partial x_1}= -\frac{2\pi\sin(2\pi x_1)}{\cos(2\pi x_1)+\frac{3}{2}},\qquad
\frac{\partial g}{\partial x_2}= \frac{2\pi\cos(2\pi x_2)}{\sin(2\pi x_2)+\frac{3}{2}},
\]
\[
\frac{\partial u_1}{\partial t}=u_1,\quad
\frac{\partial u_2}{\partial t}=-u_2,
\]
\[
\frac{\partial u_1}{\partial x_1}=2\pi\cos(2\pi x_1)\sin(2\pi x_2)e^{t},\quad
\frac{\partial u_1}{\partial x_2}=2\pi\sin(2\pi x_1)\cos(2\pi x_2)e^{t},
\]
\[
\frac{\partial^2 u_1}{\partial x_1^2}= \frac{\partial^2 u_1}{\partial x_2^2}= -4\pi^2 u_1,\qquad
\frac{\partial^2 u_2}{\partial x_1^2}= \frac{\partial^2 u_2}{\partial x_2^2}= -4\pi^2 u_2,
\]
\[
\frac{\partial^2 u_1}{\partial x_1\partial x_2}=4\pi^2\cos(2\pi x_1)\cos(2\pi x_2)e^{t},\qquad
\frac{\partial^2 u_2}{\partial x_1\partial x_2}=4\pi^2\cos(2\pi x_1)\cos(2\pi x_2)e^{-t}.
\]

Используемая разностная схема является неразделяемой: решение на новом слое ищется из единой системы линейных алгебраических уравнений (СЛАУ), которую невозможно разбить на независимые подсистемы. В такой системе неизвестные, относящиеся к разным частям решения (плотность и компоненты скорости), оказываются связанными в каждом уравнении.

\[
A\hat{S} = b,
\]
где коэффициенты матрицы \(A\) и правой части \(b\) определяются решением с нижнего временного слоя \(S\).

Неизвестные нумеруются в следующем порядке:
\[
\hat{H}_0,\; (\hat{V}_1)_0,\; (\hat{V}_2)_0,\;
\hat{H}_1,\; (\hat{V}_1)_1,\; (\hat{V}_2)_1,\;
\dots,\;
\hat{H}_M,\; (\hat{V}_1)_M,\; (\hat{V}_2)_M.
\]

В клетках таблицы указаны следующие нормы:
\begin{enumerate}
	\item \(\|v\|_{C,h} = \max\limits_{\mathbf{x}_m\in\partial_h} |v_m|\);
	\item \(\|v\|_{L_2,h} = \sqrt{[v,v]}\), где \([u,v] = (u,v) + 0.5h\sum\limits_{\mathbf{x}_m\in\gamma_h} v_m u_m\), \((v,u)=h\sum\limits_{\mathbf{x}_m\in\partial_h} v_m u_m\);
	\item \(\|v\|_{1,2} = \sqrt{\|v\|^2 + |v|_1^2}\), где \(|v|_1 = \sqrt{h\sum\limits_{\mathbf{x}_m\in\partial_h\cup\gamma_h^-} (v_{\bar{x}_m})^2}\);
\end{enumerate}
При этом $h_{x} = h_{y} = h$.

\section{Собственная реализация CGS}

Алгоритм состоит из следующих шагов:

\begin{enumerate}
	\item Задаётся начальное приближение \(S_0\) и произвольный вектор \(z^a \neq 0\). 
	Вычисляется начальная невязка \(r_0 = b - A S_0\) и полагается \(p_0 = u_0 = r_0\).
	
	\item Для \(j = 0, 1, 2, \dots\) выполняется итерационный процесс:
	
	\begin{enumerate}
		\item \(\displaystyle \alpha_j := \frac{(r_j, z^a)}{(A p_j, z^a)}\).
		
		\item \(\displaystyle q_j := u_j - \alpha_j A p_j\).
		
		\item \(\displaystyle S_{j+1} := S_j + \alpha_j (u_j + q_j)\).
		
		\item \(\displaystyle r_{j+1} := r_j - \alpha_j A (u_j + q_j)\).
		
		\item \(\displaystyle \beta_j := \frac{(r_{j+1}, z^a)}{(r_j, z^a)}\).
		
		\item \(\displaystyle u_{j+1} := r_{j+1} + \beta_j q_j\).
		
		\item \(\displaystyle p_{j+1} := u_{j+1} + \beta_j (q_j + \beta_j p_j)\).
	\end{enumerate}
\end{enumerate}
